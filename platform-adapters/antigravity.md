# Antigravity adapter

## Install

Copy this repository as one skill folder so that `SKILL.md` remains at its root:

- workspace scope: `<workspace-root>/.agents/skills/universal-writing-guide/`
- global scope: `~/.gemini/config/skills/universal-writing-guide/`

These locations and Antigravity's progressive-disclosure behavior are documented in [Google's Skills documentation](https://antigravity.google/docs/skills). The older `~/.gemini/antigravity/customizations/skills/` path is not the current documented location.

## Use

Ask Antigravity to use the **universal-writing-guide** skill for the writing task. Let its description trigger discovery, then follow `SKILL.md`: load one Layer 0 variant, only the applicable optional layers, and at most one relevant genre or subgenre file. Read a deeper reference only to answer a specific unresolved need. Do not load the repository wholesale. Use no hard token cap; retain context needed for correctness.
