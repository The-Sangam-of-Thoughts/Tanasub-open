# OpenCode adapter

## Install

Place `AGENTS.md` at the project root, or set global instructions at `~/.config/opencode/AGENTS.md`. Run `/init` in OpenCode to auto-generate or incorporate repository instructions.

```markdown
For writing tasks, read `SKILL.md` and follow its router. Load one matching Layer 0 file, then only task-relevant optional layers and one applicable genre or subgenre file. Open deeper references only to resolve a concrete need. Do not load the whole repository. Never fabricate citations or claims.
```

## Use

Launch OpenCode in the project directory. In **Plan Mode**, use `SKILL.md` to identify the required structural layer and genre guide. In **Build Mode**, execute the draft, Layer 2 humanization pass, and Layer 3 QA gate.
