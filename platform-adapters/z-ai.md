# Z.ai / ZCode adapter

## Install

Place `AGENTS.md` at the project root. ZCode ADE and Z.ai agent environments integrated with GLM models read `AGENTS.md` automatically upon workspace loading.

```markdown
For writing tasks, read `SKILL.md` and follow its router. Load one matching Layer 0 file, then only task-relevant optional layers and one applicable genre or subgenre file. Open deeper references only to resolve a concrete need. Do not load the whole repository. Adhere to craft rules and verification standards.
```

## Use

Open the project in ZCode or dispatch tasks via Z.ai CLI/chat. The GLM-powered agent ingests `AGENTS.md` as contextual system guidance and navigates `SKILL.md` for writing, editing, and QA.
