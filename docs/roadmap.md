## Equal-axis content-development program

The historical matrix contained 480 incomplete topical cells: 476 gaps and
four source-list-only partials. The current canonical tracker is
[`topic-coverage-gaps.csv`](topic-coverage-gaps.csv). Wave order expresses
content dependency, not importance.

**Current state (2026-09-23):** 480 rows are independently reviewed.
128 rows (Ch13–15) initially accepted. 384 rows (Ch01–12) reviewed and
accepted in W1–W5 with 10 issues remediated. All 32 axes have complete
chapter coverage after filling the 8 previously absent Ch10/12 sections.

Research can start for any ready downstream item, but prose authoring starts only after its dependencies and topic evidence packet pass. Within each wave, partition the 32 axes across three exclusive lanes at the whole-axis level. Every item writes its unique `proposal_path`; workers never edit `target_file`. Rotate whole-axis ownership between waves, freeze inputs at dispatch, and let only the coordinator serially integrate consolidated targets, indexes, matrices, and manifests.

## Per-item agent loop

1. **Ready check:** resolve dependencies; freeze the target file, accepted template, taxonomy metadata, source/work records, claim matrix, and open findings.
2. **Research:** inspect sources directly; record scope, counterevidence, Indian/regional search, translation and rights limits. If the evidence floor cannot be met, return `evidence-incomplete` without padding.
3. **Author:** write only the item's unique `proposal_path`. Produce mechanism → example → effect → diagnostic → revision action → scope. Do not edit `target_file` or any shared file.
4. **Author check:** validate claims, references, cultural scope, placeholders, accessibility, and preservation. Mark only `ready-for-review`.
5. **Independent review:** a non-author checks content and evidence, including all high-risk facts and required sampling. Record fail or acceptance with exact paths and hashes.
6. **Coordinator join:** integrate accepted prose serially, regenerate the relevant gap row and indexes, and run regression checks. Preserve the initial result and any later retest separately.

## Definition of done

A topic row closes only when its source and work evidence resolves, the instruction is topic- and axis-specific, the practitioner sequence is usable, counterevidence and cultural/translation limits are visible, automated checks pass, and a non-author accepts it. Human approval remains separately pending wherever publication governance requires it.

## Token policy

Keep routing and recurring instructions compact through tables, stable IDs, and on-demand evidence files. Load one axis and one topic packet at a time. Token counts guide optimization; they never justify dropping necessary evidence, rights language, cultural scope, exceptions, or verification.
