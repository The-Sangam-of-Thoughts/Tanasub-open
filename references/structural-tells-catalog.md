# Structural pattern reflection catalog

Use this catalog to diagnose prose. A match is a question to investigate, not proof of AI authorship and not an automatic edit.

| Pattern | Possible quality problem | Reflection question |
|---|---|---|
| Throat-clearing lead | Delayed value | Can the first useful claim or scene replace the announcement? |
| Generic significance | Unsupported interpretation | What changed, for whom, and according to what evidence? |
| Superficial participial tail | Added analysis without support | Does the ending clause follow from the source or merely sound explanatory? |
| Vague attribution | Unverifiable consensus | Who made the claim, and can the reader inspect it? |
| Promotional register | Evaluation replaces description | What criteria justify the praise? |
| Challenge/future-prospect ending | Outline substitutes for conclusion | What specific implication or next decision follows? |
| Automatic triad | Form controls substance | How many distinct items does the material actually contain? |
| Repeated negative parallelism | Canned emphasis | Would a direct positive statement be clearer? |
| Uniform sentence frame | Flat cadence | Which idea deserves a different shape or emphasis? |
| Uniform sentence length | Flat pacing | Where should pace change for comprehension or effect? |
| Heading stack | Fragmented argument | Can related fragments become one purposeful section? |
| Inline-header list | Artificial symmetry | Is the list scannable, or would connected prose show relationships better? |
| Excessive bolding | Competing emphasis | What one or two cues does the reader actually need? |
| Decorative em dashes | Punctuation mannerism | What logical relationship should punctuation express? |
| Repeated preview/recap | Padding | Does navigation help here, or repeat visible headings? |
| Generic metaphor | Lost specificity | What literal relation is the metaphor standing in for? |
| Citation-shaped prose | Source performance | Does the source support the exact nearby claim? |
| Smoothing disagreement | False consensus | Which positions differ, and why? |
| Committee voice | No accountable stance | What can this writer responsibly conclude? |
| Context-free advice | Weak transfer | For which reader, format, constraint, and outcome is it useful? |

Source boundary: adapted as project-authored reflection prompts from the descriptive categories in WikiProject AI Cleanup's pinned [Signs of AI writing](https://en.wikipedia.org/w/index.php?oldid=1374467046&title=Wikipedia%3ASigns_of_AI_writing), CC BY-SA 4.0. The source warns that surface indicators are neither conclusive nor confined to AI-written text.
