# Layer 2 — Contextual Humanization

Use this after the draft and storytelling pass. Preserve meaning, facts, citations, required terminology, accessibility, and the requested register. The aim is writing that sounds situated and deliberate. It is not an authorship detector or a method for disguising provenance.

## Set the voice before revising

Write one sentence for each:

- **Reader:** who will read this, what they know, and why they are here.
- **Situation:** where the writing appears and what the reader will do next.
- **Register:** conversational, professional, academic, technical, literary, or another named register.
- **Tone:** the narrator's emotional attitude, chosen from `tones/` (or none), and the genre engine it must not override. Stakes belong to the genre; texture belongs to the tone; formality belongs to the register.
- **Speaker:** the stance, experience, and limits the writer can honestly claim.
- **Meaning lock:** facts, qualifications, quotations, and terms that cannot change.

If these are unknown, infer them from the request and mark uncertain choices. Do not default every piece to casual speech. Natural academic prose, legal instructions, and an Instagram caption use different vocabularies and rhythms.

## Paragraph pass

Revise one paragraph at a time.

1. **Purpose:** What new work does this paragraph perform? Cut it if it only announces, repeats, or praises the topic.
2. **Specificity:** Replace generic importance, impact, or trend language with the concrete fact, mechanism, example, or consequence meant.
3. **Register:** Would this reader expect these terms here? Keep precise technical language when it earns its place; explain it when the audience needs help.
4. **Default wording:** Is a word present because it is exact, or because it was an easy continuation? Prefer the exact word. Do not replace a good word merely because it appears in an awareness list.
5. **Cadence:** Read the paragraph aloud. Vary sentence length and shape when repetition is audible. Do not chase a numeric rhythm rule.
6. **Structure:** Remove throat-clearing, canned transitions, redundant section previews, automatic triads, and restated conclusions when they add no function.
7. **Voice:** Add an honest judgment, bounded observation, concrete detail, or useful qualification where the piece has become smoothly anonymous.
8. **Integrity:** Recheck that compression, informality, and vivid language have not altered the claim or fabricated experience.

## Four reflection levels

### Word

- Would the target reader or writer use this word in this situation?
- Does it name the thing precisely, or hide it behind abstraction?
- Does nearby prose repeat the same intensifier, transition, or metaphor?
- Is specialist language necessary and, if so, is it explained at the right depth?

### Sentence

- Does the sentence lead with its useful claim or action?
- Have several sentences repeated the same grammatical frame?
- Is every qualifier necessary for accuracy?
- Would punctuation clarify the thought, or merely decorate it?

### Paragraph

- Does the first sentence give the reader a reason to continue?
- Does each later sentence develop the same purpose rather than circle it?
- Is a list genuinely easier to scan than prose?
- Does the ending land on evidence, consequence, decision, image, or next action instead of a generic uplift?

### Document

- Does one recognizable speaker make consistent choices?
- Are claims as confident as the evidence permits?
- Could any paragraph be pasted into an unrelated piece without changing? If so, make it specific or remove it.
- Does the structure serve this task, rather than imitate a universal template?

## Compact awareness prompts

These are prompts, never bans.

| Pattern | Ask before keeping it |
|---|---|
| `delve`, `explore`, `unpack` | Which exact action follows—compare, test, describe, or explain? |
| `landscape`, `realm`, `space` | Can I name the market, field, tools, people, or setting? |
| `robust`, `powerful`, `seamless` | What observable property supports the adjective? |
| `pivotal`, `crucial`, `vital` | What changed because of it, and is that change evidenced? |
| `underscores`, `highlights` | Can the evidence and conclusion be stated directly? |
| `foster`, `enhance`, `elevate` | What actor causes what measurable or visible change? |
| `tapestry`, `journey`, `testament` | Is the metaphor doing real explanatory work? |
| `furthermore`, `moreover`, `additionally` | Does the relationship need a transition, or can the next claim begin? |
| `in today's world`, `in an era` | What date, condition, or development actually matters? |
| `it is important to note` | State the important point itself. |
| `not only … but also` | Does the parallelism sharpen meaning or merely inflate it? |
| exactly three bullets | Are there truly three independent items? |
| repeated em dashes | Would a period, comma, parenthesis, or rewrite better express the relation? |
| abstract wrap-up | Can the piece end on a decision, implication, next step, or concrete detail? |
| vague attribution | Who says this, where, and with what evidence? |
| promotional praise | Is this evaluation requested and supported, or should it become description? |
| hedged balance | Which position does the evidence support? Retain uncertainty only where real. |
| uniform sentence lengths | Where should the reader pause, accelerate, or dwell? |
| repeated section previews | Does the reader need navigation here, or can the section start? |
| generic applicability | What makes this advice specific to this reader, format, and subject? |
| forced triads (rule of three) | Are there genuinely three independent items, or would two or four be more honest? |
| contrast constructions ("not X, but Y") | Does the parallelism sharpen meaning, or is it staging a dramatic reveal? |
| one-line dramatic closers | Does this sentence earn its standalone weight, or is it performing profundity? |
| decorative bolding | Does the emphasis serve the reader, or does it simulate energy in thin content? |
| unnecessary list-ification | Would flowing prose serve this content better than a bulleted list? |
| significance inflation | Is this genuinely a watershed/paradigm/revolution, or is an incremental change described accurately? |
| chatbot conversational wrappers | Has scaffolding language ("Certainly!", "I hope this helps") been removed? |
| self-referential affirmations | Does the text describe what it will do instead of doing it? |
| tonal drift | Can I name the tone of each section, or has the voice wandered from its brief? |
| tonal whiplash | Does the tone switch abruptly between incompatible attitudes without a bridge? |
| monotone-tone saturation | Has one tone run unbroken so long that it flattens the piece's contrast? |
| tone-register mismatch | Does the tone's emotional attitude sit oddly against the register this reader expects? |

## Return rules

- If facts or intent changed, return to Layer 0.
- If the opening, tension, or progression weakened, return to Layer 1.
- If voice or cadence still feels generic, repeat Layer 2 on the failing passages.
- Then run Layer 3. Record unresolved choices rather than claiming a subjective pass as objective fact.
